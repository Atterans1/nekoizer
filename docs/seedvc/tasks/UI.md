# UiAgent task
Files you own: R/ui/__init__.py, ui/server.py, ui/hotkeys.py, ui/static/index.html, app.js, style.css, ui/fake_pipeline.py (TEST-ONLY mock of the Pipeline interface; never imported by product code), R/tests_seedvc/test_ui_server.py, test_hotkeys.py.
Build (spec section 4 + the ui/ part of CONTRACT.md):
1. ui/server.py: FastAPI CreateApp(pipeline) with the REST + WebSocket API of CONTRACT.md against any object implementing the Pipeline interface (Telemetry, GetParams, SetParam, ApplyPreset, SetSlotFromWav, ClearSlot, SetManualSlot, StartRecording, StopRecording, ListDevices, LevelSnapshot). GET /api/state returns params + ParamSpec ranges/defaults (read from seedvc_params at runtime) + slot info + presets (three real ones plus the truncated fourth with its label and disabled flag) + telemetry. POST /api/param validates with seedvc_params.Validate and answers 400 with the message on bad values. POST /api/slot/{i} takes a multipart .wav (reject non-wav; slots 0..3 only), decodes with soundfile, calls SetSlotFromWav(idx, float32 mono, sr). /ws pushes telemetry + recorder level/waveform/clipping at about 20 Hz and ends cleanly when the client leaves. Bind 127.0.0.1 only.
2. ui/static: minimal dark single page, fully local (no CDN, no external requests), keyboard accessible, semantic HTML with labels. Header: title, pipeline status, input mode/device, output device, latency + underruns, balancer state. Reference bank: four slot cards named by SLOT_NAMES, each with a drag-and-drop .wav zone plus a file input fallback, a Record button (up to 10 s, live waveform canvas, clipping meter that turns red when clipping), a Select button for manual mode, loaded state with duration. Tone rack: sliders built at runtime from the API ranges (pitch_shift_st, formant_shift, f0_expander, cfg_rate, diffusion_steps, left_context_s, block_ms, overlap_ms, timbre_mix, monitor_volume) with live readouts and per-control reset, toggles for monitor_enabled, auto_balancer, and emotion mode auto/manual. Presets: the three real ones via /api/preset; the fourth a disabled button labelled 'Ultra-Low-... (name cut off in spec)' that does nothing (R20). Hotkey hint Ctrl+Alt+1..4.
3. ui/hotkeys.py: Ctrl+Alt+1..4 via ctypes RegisterHotKey/UnregisterHotKey on a dedicated thread with its own message loop, calling callback(idx); Janitor cleanup unregisters and ends the thread. Report per combination whether registration succeeded on this machine.
