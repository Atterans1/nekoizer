Reference bank

Hotkeys: Ctrl+Alt+1 to 0 select a slot for manual mode. Drop a .wav on a card, choose a file, or record up to 10 s. Drop a .pth, .zip or .index file on a card to add an RVC voice. Auto emotion mode uses reference clips only. An RVC voice is chosen with its slot's Use this voice button, Select for manual, or Ctrl+Alt+1 to 0.

Any wav, flac, ogg or mp3 file works from your computer too: drop it on a slot. voice-models.com lists RVC voices, and Nekoizer runs them now: download a voice's zip and drop it on a slot, or paste a direct link to a .zip or .pth file above. Links to Google Drive or to web pages cannot be fetched: download the file yourself and drop it on a slot. Only use voices you have the right to use.
